## 📦 Local Workspace Setup Steps

### 🎬 1. Netflix Clone
```bash
git clone https://github.com.git
cd Netflix-Clone
npm install
npm run dev
```

### 🤖 2. ChatGPT Clone
```bash
git clone https://github.com.git
cd ChatGpt-Clone
npm install
npm run dev
```

### 💬 3. Evangadi Forum
```bash
git clone https://github.com.git
cd Evangadi-Forum
cd backend && npm install
cd ../frontend && npm install
```
